# Problem: Longest Common Prefix (Easy)

**LeetCode Link:** https://leetcode.com/problems/longest-common-prefix/

## Approach

Compare the first string with each remaining string.

Keep only the characters that are common at the beginning of all strings.

## Time Complexity

O(n × m)

## Space Complexity

O(m)

## Notes

The program finds the longest prefix shared by all given strings.
